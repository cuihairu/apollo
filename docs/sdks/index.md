# SDK 文档

Apollo 的客户端 SDK 负责把服务端协议、属性同步、会话和消息路由能力封装到客户端侧。

当前仓库先收口 Unity 文档和实现说明，后续再按相同协议语义扩展到其它平台。

## 入口

- [Unity SDK 目录结构](./unity/SDK_Structure.md)
- [Unity 属性同步 SDK](./unity/Attribute_SDK.md)
- [项目目录结构说明](../Directory_Structure.md)

## 当前状态

- `sdks/`：Unity C# SDK 源码
- `skds/`：Cocos / Laya / 历史 SDK 工作区
- `docs/sdks/`：SDK 文档站内入口
