# Q4：Apollo 为什么不实现无缝大世界？房间之间如何切换？

Apollo 面向以一场对局为边界的轻量多人游戏。它不实现玩家在多个空间模拟进程之间连续漫游的持久化无缝大世界，因此不需要 Cell 空间切片、Ghost 镜像或跨 Cell 边界接管作为基础架构。

房间之间的转换是一次明确的玩法流程：客户端请求离开当前 Room 或完成结算，再通过匹配/房间分配进入目标 Room。若玩家需要跨 CellApp 移动，则迁移其唯一权威运行对象：源端冻结并导出，目标端恢复并确认接管，之后更新在线路由并清理源端。任何时刻只能有一端处理输入、推进状态或执行权威写入。

这项跨 CellApp 权威迁移仍是待实现目标。当前代码原型没有完整的 Room 管理、匹配接入和端到端路由迁移。当前范围与验收项见根目录 [`todo.md`](https://github.com/cuihairu/apollo/blob/main/todo.md)。
