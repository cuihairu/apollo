## 2. 管理日志完整记录（journal v2）

现状 v1（批㉚）只落代次墓碑。v2 把分配与启动代次纳入同一 append-only 文本日志，一行一类，前缀区型：

| 行 | 格式 | 语义 |
|---|---|---|
| T（可省前缀） | `T cell_id\|start_epoch` 或 v1 裸 `cell_id\|start_epoch` | 代次墓碑（现状语义不变；装载取每 cell 最大值） |
| A | `A space_id\|cell_id\|version` | 认领/重认领（版本单调前进的每次转移都记一行） |
| R | `R space_id` | 过期释放（owner→0、版本不变；重放时以每 space 最后一条 A/R 为终态） |
| B | `B management_epoch` | World 启动代次行（每次启动一行；装载取最大值 +1 铸新代次） |

- **写序（write-ahead）**：`A` 行 append+flush 成功才推 962——持久决定先于对外声明。现状 `recordEpochWatermark` 先于 `pushSpaceAssignments` 的调用序即此纪律的 v1 形态；v2 把分配记录补进同一序。`B` 行在监听开之前写（先铸代次再开受理面）。
- **装载**：逐行严格解析，损坏行拒启（v1 纪律沿用，不静默部分回放）。重放终态 = 每 space 最后一条 A/R + 每 cell 最大 T + 最大 B。
- **空值语义**：v1 裸行按 T 解析（既有文件直接升级，不迁移）。
- **空日志顶替禁令的落地判定**：journal 配置开但文件缺失时无从区分首启与记录丢失。判定规则——**有 cell 断链重拨进来（证明曾存在旧管理关系）而 journal 无该 cell 的任何 T 行 = 记录缺失证据，该 cell 全部 Space 冻结对账、不开新分配**；无任何 cell 拨入的真空文件缺失按首启受理（无外部证据可反证）。cell 侧重拨是批㉓ 已落地面，无需新机制。
- **compaction**：首版不压缩（append-only，上界 = 分配变更频率）；快照 + rename 方案（Windows 先删后 rename 坑账）留到压缩批。

- **不新增下行裁决帧**：裁决落地即经既有 962 全池权威视图（匹配 = 照推、cell 侧无据 = ready=0 撤销标记、到期 = 释放）。冻结不经协议下发——cell 侧冻结沿用批㉗ 失联/复核语义与 961 裁决拒（code 3 自冻结）。

## 4. 逐项裁决表

journal 记录（重放终态，批B 起即权威归属表内存态）× cell 自报（967）逐项核对：

| journal | cell 自报 | 裁决 | 落地面 |
|---|---|---|---|
| S owner C v N | C 报 S v N、mgmt 同 | **匹配，保持** | 962 照推 |
| S owner C v N | C 报 S v M≠N | **版本冲突：S 冻结待对账** | World 冲突集（观测面）+ 该 cell 该 Space 冻结；不推新分配、不释放 |
| S owner C v N | C 未报 S | journal 权威：cell 已丢 → 既有撤销/到期路径 | 962 ready=0 或批㉘ 释放/重认领 |
| 无 S 记录 | C 报 S v M | **未登记权威：S 冻结（源隔离不明）** | 同冲突集；journal 补 A 行（人工/后续批）后才解 |
| S owner C | C 过期窗不来 | 既有释放/重认领 | 批㉘ 面（版本 +1 防 ABA） |
| — | C 走入代次 < 水位 | code 3 拒 + cell 自冻结 | 批㉗/批㉚ 面 |

冻结粒度 = **单个 Space**，不整 cell 冻结（隔离最小化：同 cell 其它 Space 照常受理与分配）。冲突 Space 的解冻 = 对账修复后 World 补记 journal 并重推 962；是否需人工命令见 §6 待拍板。

## 5. World 重启时序

1. 持久卷锁检查（活锁拒启，见 §6）。
2. journal 装载（损坏拒启——v1 已落地纪律）。
3. 铸新管理代次 = 最大 B + 1，写 `B` 行（先记后开受理面）。
4. 监听开；cell 断链重拨（批㉓）→ 961 代次裁决（水位拦旧端，批㉗/批㉚）。
5. 受理后 cell 发 967 自报；World 按 §4 逐项核对，进冲突集或保持。
6. 无冲突（且无空日志缺失证据）→ 分配闸开 = 恢复完成；有冲突 → 仅冲突 Space 冻结，其余照常。
7. 稳态：后续注册/重拨照旧走 961 + 962（967 随每次 961 受理重发自报；重复 967 幂等受理不重裁决）。

## 7. 验收清单（并入 todo 用）

- kill World → 同 journal 重启 → cell 重拨 + 967 匹配 → 保持、分配闸开；
- 版本冲突（journal 落后于 cell 应用版本——如 append 失败降级窗）→ 冲突 Space 冻结、其余照常、解冻后恢复；
- cell 自报 Space 而 journal 无记录 → 未登记权威冻结；
- journal 配置开 + 文件缺失 + 有 cell 拨入 → 全冻结不分配；无 cell 拨入 → 首启受理；
- 坏行拒启回归；活锁拒启；旧代次 code 3 回归。
