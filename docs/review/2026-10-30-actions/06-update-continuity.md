## 2. D20 · cell 更新（先自然排空）

### 2.1 排空更新多进程演练

```
1. 停止新分配（963 begin_retire：置意图，停止新认领并归还其分配）
2. 观察活动归零（967 自报对账 + 活动计数）
3. 退出（cell 退出 → World 回收分配）
```

- 验收：排空期间已接活动正常结束；无新分配进入；退出后 World 分配回收、可重挂新 cell。

## 4. D22 · Base 更新演练（单区服，前置 L154/L155）

```
一玩家、两 Base：
1. 交接长期对象/会话/待办 → 新 Base
2. 提交写权代次（持久生效）→ 隔离旧写
3. 刷新 Base 路由 → 清理旧 Base
注入：旧 Base 迟到保存（写权校验拒绝）、旧 Base 重启（拒旧）
断言：拒旧生效、奖励待办不丢、无第二个资料写入者
```

## 5. D23 · World 管理端更新（首阶段：同卷、受控停止重启）

### 5.1 管理状态清单

| 状态 | 来源 | 恢复 |
|---|---|---|
| 拓扑/分配 | journal A/R/B/T 行 | 装载终态重建 |
| 注册代次 | B 行 + 水位 | 铸新代次 = 最大 B + 1 |
| 容量/排空 | 内存态 + 967 自报 | 重启后 cell 自报对账（§4） |
| 在途创建/迁移决定 | 提交记录 | 按提交记录恢复 |

### 5.2 用例

| # | 用例 | 断言 |
|---|---|---|
| 1 | 旧端未退出拒启 | 持久卷锁强制拒启（活锁 PID 报错） |
| 2 | 新端恢复旧归属 | journal 重放终态 = 旧归属 |
| 3 | 在途决定恢复 | 提交记录恢复，不重复分配 |
| 4 | 管理记录写入失败 | 纳入 S05（B/关键水位失败拒启或冻结） |

## 6. D24 · 管理失联宽限与冻结时间线验证

- 基线：心跳 5s、cell 宽限 15s、World 过期 30s（开发验证基线，非生产承诺）。

| # | 场景 | 时间线检查 |
|---|---|---|
| 1 | 断链 | 停止新输入的时刻 |
| 2 | 回执持续丢失 | 停止外部副作用的时刻 |
| 3 | 宽限到期 | cell 冻结推进（先停推进） |
| 4 | World 重启 | 过期后考虑释放（后释放） |
| 5 | 旧端复活 | 对账后恢复，不自动故障接管 |

> 明确不做：不在实际业务配置中用「0=永不冻结」；不将 15/30 秒当生产服务承诺；延后自动接管。
