## 1. D05 · 「提交 → 发布 → 目录接收 → 网关缓存」时序

### 1.1 时序（单 World 位置发布）

```
[World] 分配决定 → journal A 行 fsync（先落介质再发布）
   → 962 分配应用（cell 认领）→ 位置投影消息（space_id, cell_id, 拓扑版本, 权威代次）
[loginServer 目录] 接收 → 更新查询投影（按拓扑版本水位比较）
[gateway] 查目录缓存 → 按路由版本命中当前 cell
```

### 1.2 重复 / 乱序 / 目录重启行为

| 情形 | 行为 | 规则 |
|---|---|---|
| 重复投影（同一版本重发） | 幂等受理 | 版本 ≤ 当前水位则忽略 |
| 乱序（旧版本后到） | 拒绝旧版本 | 只接受版本 ≥ 当前水位 |
| 目录重启 | 从 World 重放发布重建；地址/就绪**重新确认**后才放行 | 版本水位与恢复闸优先 |
| 找不到位置 | 不自行挑 cell | 回退到 World 分配事实源（管理日志），不二次分配 |

> 目录不成为第二个分配者；地址/就绪信息必须重新确认，不能落盘地址直接复用。
> 明确不做：延后独立高可用目录集群；interfaces 端口不作本功能硬依赖。

### 1.3 验收（先单 World）

1. 单 World 位置发布：分配 501 → 目录收到 501→cell-21 投影 → 网关查址命中。
2. 重建：目录重启后从 World 重放恢复投影，地址确认前不放行。
3. 乱序/重复注入：旧版本投影被拒、重复投影幂等。

## 2. D06 · 玩家归属与位置记录字段语义

### 2.1 字段表（四组：身份 / 资料归属 / 模拟位置 / 会话）

| 字段 | 组 | 含义 | 权威写入方 | 稳定范围 | 何时变化 |
|---|---|---|---|---|---|
| `player_id` | 身份 | 玩家唯一 ID | Base | 终生不变 | 不变化 |
| `home_zone_id` | 身份 | 原区服（**身份背景**，非业务区服 ID） | 建号 | 终生不变 | 不变化（不直接当业务区服标识） |
| `base_id` / 归属版本 | 资料归属 | 当前 Base 承载 | Base（写权代次） | 变更时 | Base 更新/负载调整 |
| `world_id` | 模拟位置 | 所属 World | World | 稳定 | 跨 World 迁移（暂不启用） |
| `space_id` | 模拟位置 | 当前空间 | World | 稳定 | 显式换场 |
| `cell 分区` | 模拟位置 | 空间内分区（首阶段 = scene id） | World | 稳定 | 多 Cell 才变 |
| `执行进程` | 模拟位置 | cell_id | World | 稳定 | cell 重启/迁移 |
| `instance_id` | 模拟位置 | 临时玩法 | World | 玩法生命周期 | Instance 创建/销毁 |
| `模拟代次` | 模拟位置 | 实体权威代次 | World/cell | 迁移时 +1 | 迁移/重启 |
| `gateway_id` / `session` | 会话 | 当前网关/会话 | gateway | 会话期 | 重连/换网关 |
| `会话版本` | 会话 | 会话代次 | gateway | 会话期 | 旧会话撤销 |

> 关键区分：**资料归属（Base）** 与 **模拟位置（cell）** 是两回事——换地图不搬资料归属；
> **会话** 与 **实体** 分离——重连不重建实体。

### 2.2 示例一「换场但 Base 不变」

```
player p=42, home_zone_id=101, base_id=base@9201, world_id=1, space_id=502(lobby),
cell=cell-21, instance_id=∅, 模拟代次=3, gateway=g1, 会话版本=1
→ 显式换场到 space_id=504(duel), cell=cell-22
→ 结果：space_id=504, cell=cell-22, 模拟代次=4, instance_id=inst-88,
   base_id 不变（仍 base@9201）, home_zone_id 不变, player_id 不变
```

### 2.3 示例二「重连但实体不重建」

```
player p=42 在 space_id=504（cell-22）掉线（gateway g1 断开）
→ 重连经 gateway g2：会话版本 +1，旧会话撤销；实体 e=777 不重建（模拟代次不变）
→ 结果：gateway_id=g2, 会话版本=2, 模拟代次=4 不变, space_id=504 不变, 实体保留
```

> 明确不做：延后一次性大范围序列化替换；不用进程 IP 充当身份。

## 3. D07 · 版本职责表与迟到消息裁决表

### 3.1 版本职责表（六类版本，各自分配者与拒旧规则）

| 版本 | 含义 | 分配者 | 拒旧规则 |
|---|---|---|---|
| 进程代次 | 进程重启次数 | 各进程 | 水位以下注册拒（code 3 + 自冻结） |
| 资料写权代次 | Base 写权 | Base（存储校验） | 旧写被隔离 |
| 实体权威代次 | 谁能推进实体 | World/cell | 旧权威输入拒 |
| 拓扑版本 | 布局变了 | World | 旧布局消息拒 |
| 路由版本 | 位置路由 | World | 旧投影拒（D05 §1.2） |
| 会话版本 | 会话代次 | gateway | 旧会话迟到输入拒 |

### 3.2 迟到消息裁决表

| 迟到消息 | 对照版本 | 裁决 |
|---|---|---|
| 旧注册/重拨 | 进程代次 vs 水位 | code 3 拒 + cell 自冻结 |
| 旧投影 | 路由版本 | 拒（版本 < 当前水位） |
| 旧权威输入 | 实体权威代次 | 拒（旧权威不生效） |
| 旧会话输入 | 会话版本 | 拒（旧会话已撤销） |
| 旧写回 | 资料写权代次 | 存储写权校验隔离 |

> 明确不做：延后多版本长期共存；不把各版本联动递增作为省事方案。
> 验收（接 L172 兼容矩阵）：位置查询链做一次端到端字段往返与旧代次拒绝。

| 版本对 | 控制协议 | 业务消息 | 快照 | 客户端 |

### 4.2 规则

- 当前严格同兼容投影；仅在 L172 验证具体版本对后加入受限兼容清单；
  清单同时绑定业务解码和快照转换能力。
- 未有任何证据的组合继续拒绝并自冻结（不撤销现有 code 5 隔离行为）。

## 5. D37 · 登录/结算链跨进程关联字段与缺口

### 5.1 关联字段（现状）

- 日志行可携带：`component_id`（进程）、`player_id`（部分路径）、`space_id`/`cell_id`（分配路径）。
- 现状**无统一 request/玩法/迁移 trace ID** 跨进程贯穿；自研日志/指标未集成 OpenTelemetry。

### 5.2 缺口与设计

| 链路 | 现有关联 | 缺口 | 设计 |
|---|---|---|---|
| 登录链 | 认证/会话/激活/准入/创建 各段 | 段间无同一 request_id 贯穿 | 定义 `trace_id`（登录链）+ `request_id`（每段），日志统一输出 |
| 结算链 | settlement_id 局部 | 结算意图→各 Base 确认 无跨进程 ID | 用 `settlement_id`（稳定玩法 ID + 结算 ID）贯穿 |
| 迁移链 | 迁移决定 | 无迁移 ID | 定义 `migration_id`，源 World 持久记录贯穿 |

> 触发条件：达到难以定位跨服务故障后，选其中一条验收 SDK/exporter 试点（当前不集成 SDK）。

### 5.3 验收（触发后）

采样与导出故障隔离：exporter 不可达时游戏模拟不受阻（背压/降级），自研 span 不代表 SDK 集成。
