## 2. S02 · spawn 批启动凭据源与监督归属

### 2.1 凭据规则（签发者/验证者/有效期/用途/续期）

| 项 | 规则 |
|---|---|
| 签发者 | World（短时、限定 cell 身份/启动代次/所属 World） |
| 验证者 | World 收到 960 注册时校验 |
| 有效期 | 短时（启动窗 + 宽限），过期即拒 |
| 用途 | 绑定注册操作（注册/重注册），不通用 |
| 续期 | 重注册同身份 = 服务身份续期（有效代次内） |
| 传输 | 开发模式：受限文件或继承句柄传递；生产留替换接口 |

### 2.2 负例

| # | 负例 | 断言 |
|---|---|---|
| 1 | 错误身份 | 凭据所属 cell 与注册 cell_id 不符 → 拒 |
| 2 | 过期 | 凭据过期 → 拒 |
| 3 | 重复使用 | 同凭据重复注册 → 代次仲裁 |
| 4 | 冒用 | 被另一 cell 冒用（身份不匹配）→ 拒 |

- 不生成生产密钥，本次不运行 spawn；延后远程主机启停和复杂密钥平台接入；
  **一个子进程只由一处监督重启**（World 与 machined 不同时监督同一 cell）。

## 3. S03 · 负载/能力上报与容量消费

### 3.1 最小容量指标（每项：单位/采样窗/过期时间/消费者）

| 指标 | 单位 | 采样窗 | 过期 | 消费者 |
|---|---|---|---|---|
| 当前持有 Space 数 | 个 | 每次 967 自报 | 注册窗 | World 分配 |
| 容量槽位 | 槽 | 上报窗 | 心跳窗 | World 准入 |
| 能力位（capabilities） | 位掩码 | 注册时 | 无 | World 过滤（复用已有） |
| 负载（活跃实体） | 个 | 周期上报 | 心跳窗 | 后续扩展（本轮无消费者） |

### 3.2 三类选择验证（两能力不同 cell）

| # | 场景 | 断言 |
|---|---|---|
| 1 | 有容量 | 合格 cell 被选 |
| 2 | 无容量 | 明确拒绝或等待（不是放到不合适进程） |
| 3 | 指标过期 | 视为不可用，拒/等 |

> 明确不做：延后增加无消费者字段和实时自动搬迁；不重复实现已有能力位过滤。

## 4. D35 · 真实帧大小/带宽/耗时采样协议（触发后）

- 采样：实际帧大小、带宽、处理耗时（真实链路运行时）；
- 记录：换编码要解决什么（每帧大小/解析耗时）、压缩要节省什么（带宽/传输）；
- 确有瓶颈时只选一条消息路径试验，不全量重写/默认压缩。

## 5. D36 · 可重复负载与 tick 耗时基线

### 5.1 可重复负载定义

N 个实体、M 个 Space、固定 tick 预算；确定性种子，可复现。

### 5.2 基线测量

| 项 | 目标 |
|---|---|
| tick 耗时基线 | 记录平均/尾部延迟（p95/p99） |
| 负载梯度 | 每档 N 的 tick 耗时曲线 |
| 问题清单 | 希望 Profiler 回答的具体性能问题 |

- 可复现负载先准备好，工具采样才易解释；自研指标不冒充专用 Profiler；
  出现瓶颈即可提前启用短期采样（不必等全部架构完成）。
