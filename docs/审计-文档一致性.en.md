# Audit: Documentation Consistency (docs vs source)

> Audit standard: 《文档与源码一致性审计规范》 three discrepancy classes + six steps.
> Fix documentation toward the source of truth (the code); never rewrite code to fit
> documentation.
> Audit date: 2026-10-13. Audit surface: README.md / README.zh.md, all docs/ pages,
> design documents, API/config descriptions, and the public facade
> (`gh repo view` description/homepageUrl/topics).
> Evidence discipline: every claim carries `file:line`; negative conclusions first
> verify the search path exists (empty grep ≠ absent); historical/ADR contexts
> ("old stack", "retired", "P4-4 batch ⓪ nng migration base") do not count as drift.
